# How-to guides

Directions to one goal each, for someone who has installed consequitur and knows what a thread is. Each page is one goal and its steps; the options are in the [reference](../reference/README.md).

- [How to write a schema](write-a-schema.md): a domain in JSON, read with `readSchema`, and the same in KDL with `consequitur-kdl`.
- [How to add a kind to a kit](add-a-kind.md): a rule kind of your own, and where a handle kind or a law kind differs.
- [How to be the authority of a thread](be-the-authority.md): state the writer, post with your clock, store the lines, read a refusal, verify a stored thread.
- [How to preview a draft in a web page](preview-a-draft.md): the dry run while composing, the thread drawn, its changes animated, the band.
- [How to consolidate two threads](consolidate-two-threads.md): the replay, the derived schema and its conflicts, the drill, the seals.
